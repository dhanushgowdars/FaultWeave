# Phase 19C.2C — Opt-in healthy v2 collector pilot

**Status:** candidate live collector, not accepted v2 training data.

## Purpose

Produce a single **genuinely collected**, research-only, healthy 60-second
65-feature vector under new `data/datasets/v2/pilot/<run_id>/`. Do not modify
v1 data, Model v1, banking transfer/recovery, Docker configuration, fault controls,
or v2 training/calibration. No randomized challenges.

## Safe operating contract

- Default `--dry-run` performs no network, Docker, or file writes.
- `--execute` is explicitly opt-in: runs 75 seconds of **new simulated**
  `/api/v1/transactions` traffic at 2 requests/s through localhost port 18110.
  This workload may create **synthetic research transaction records** in the
  local PostgreSQL instance. It does not invoke the banking transfer API.
- Requires seven healthy containers and no existing fault-control file **both**
  before and after collection. Never removes another run's fault.
- Client `run_id` is recorded from the HTTP header generated by this invocation,
  not invented for old v1 requests. Structured events are actual run-correlated
  Docker logs. Capture uses a field allowlist to avoid persisting arbitrary log
  payloads and credentials.
- Uses Phase 19C.2B to select a strict 60-second window with timestamp and
  telemetry coverage proof; never pads a short window or adds historical data.
- Writes raw proof, candidate features, and SHA-256 manifest with exclusive
  creation. All are `diagnostic_only` with `training_eligible=false` and
  `threshold_tuning_eligible=false`; **no true fault label is asserted**.
- Fails rather than writing incomplete or uncorrelated artifacts. No model
  inference or training in this script.

## Acceptance and next work

If the pilot fails, preserve the error and inspect log correlation/timing; do
not weaken the strict v2 feature builder. Once one healthy pilot passes, design
and separately approve a controlled fault pilot, run-level split design, variable
loads and a genuinely unseen unknown-fault holdout. Current collector is not a
fault-pilot generator or a v2 training pipeline.
